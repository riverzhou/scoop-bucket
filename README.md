# rustmd Scoop bucket

[rustmd](https://github.com/riverzhou/rustmd) is a local-first notes app for Markdown, HTML, CSV, TXT and JSON (plain files, offline, no account).

```powershell
scoop bucket add riverzhou https://github.com/riverzhou/scoop-bucket
scoop install rustmd
```

Update with `scoop update rustmd`; remove with `scoop uninstall rustmd`.

The manifest lives in [`bucket/rustmd.json`](bucket/rustmd.json) and follows the latest GitHub release.
